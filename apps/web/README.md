# IQstatS Web

Frontend Next.js della dashboard personale. Le chiavi risiedono nel file locale `.env.local`, escluso da Git; nessun segreto è disponibile nel browser.

## Avvio

```powershell
npm.cmd run dev
```

La prima release include dashboard dimostrativa, dettaglio di tre partite brasiliane e endpoint diagnostico `GET /api/health`.
